# Kordal – Videojuego 2D en Unity

## Descripción
El proyecto consiste en el desarrollo de un videojuego 2D utilizando el motor Unity, basado en un
sistema de niveles independientes centrados en el combate cuerpo a cuerpo. A diferencia de un
juego de desplazamiento lateral, el jugador se enfrentará a escenarios cerrados donde deberá
derrotar a todos los enemigos para avanzar.
La historia se desarrolla en un entorno oscuro y subterráneo. El protagonista es un luchador que,
tras caer en una grieta, queda atrapado en una cueva que conecta con el inframundo. En este
lugar habitan esqueletos reanimados que custodian un núcleo oscuro que mantiene activo este
mundo.
El objetivo del jugador será avanzar a través de distintos niveles derrotando enemigos cada vez
más fuertes, hasta alcanzar el origen de la corrupción y destruirlo para poder escapar.

## Características principales
- Movimiento lateral del personaje
- Salto, caída y colisiones
- Niveles lineales con inicio y final
- Enemigos básicos con patrones simples
- Sistema de vidas y puntuación
- Interfaz de usuario (UI)
- Música y efectos de sonido

## Estado actual del proyecto
- Player configurado con Rigidbody2D y BoxCollider2D
- Movimiento básico implementado
- Animaciones Idle y Run funcionando
- Suelo con Tilemap y colisiones
- Estructura inicial del proyecto creada

## Tecnologías utilizadas
- Unity 2022+
- C#
- Aseprite (sprites)
- GitHub (control de versiones)

## Objetivo del proyecto
Desarrollar un prototipo funcional que incluya movimiento, animaciones, enemigos, niveles y una interfaz básica, siguiendo una planificación estructurada.
